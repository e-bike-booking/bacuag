I-download ang E-Bike App

Dalawang app sa iisang install — mag-login bilang Passenger o bilang Rider (E-Bike driver). Poblacion Bacuag at Siwata lang ang sakop ng mapa, may offline map at live GPS tracking.

Passenger App

Para sa Pasahero — mag-book ng biyahe

  • Book ng E-Bike papuntang Poblacion Bacuag at Siwata
  • Live GPS tracking ng rider + countdown timer ng hintay
  • Offline map — gumagana kahit walang internet
  • Verified ID signup (auto-fill ng pangalan mula sa ID)
I-download ang Passenger App (APK)

Rider App

Para sa Rehistradong E-Bike Driver

  • Tanggapin ang booking na may sound notification
  • Oras ng pag-book ng pasahero at 10-minutong waiting time
  • Real-time GPS sync ng ruta papuntang pickup/destination
  • Auto-arrival detection sa loob ng 45 m radius
I-download ang Rider App (APK)

Parehong APK ang gamitin — sa login screen, piliin ang inyong role (Passenger o Rider). Kasama na ang demo accounts: rider@sakaybacuag.ph / rider123 at passenger@sakaybacuag.ph / passenger123.
